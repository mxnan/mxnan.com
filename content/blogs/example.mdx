# Typography & Color System

This post is an **MDX playground** for your blog styling. It’s designed to exercise the full Tailwind Typography (`prose`) surface area while staying **theme-safe** (light/dark) by using semantic colors and neutral tokens.

---

## The rules (what “theme-safe” means here)

- No hardcoded hex colors.
- Prefer **semantic** tokens (e.g. foreground/background) and neutral scales.
- Links should be obviously interactive.
- Code should be legible and wrap safely.

> If this page looks good, your system is in a great place.

## Cursor Effects

<div className="grid gap-4 md:gap-6 not-prose">

  {/* 1. Default */}

    <div className="mt-4">
      <span className="inline-flex items-center rounded-full bg-muted px-3 py-1 text-xs">Default (no data-cursor)</span>

  <div className="rounded-xl border border-border bg-zinc-950 p-6 text-white" data-cursor="blend">
    <div className="text-sm font-semibold text-white mb-1">Blend Dither</div>

      Creates a beautiful inversion effect that looks premium on any background.
    </div>
    <div className="mt-4">
      <span className="inline-flex items-center rounded-full bg-white/10 px-3 py-1 text-xs">data-cursor="blend"</span>
    </div>
  </div>

  {/* 3. Takeover */}
  <div className="rounded-xl border border-border bg-violet-950/80 p-6 text-white" data-cursor="takeover">
    <div className="text-sm font-semibold text-white mb-1">Takeover</div>
    <div className="text-sm text-violet-300">
      The cursor takes the shape and size of the element it's hovering over,

    </div>
    <div className="mt-4">
      <span className="inline-flex items-center rounded-full bg-white/10 px-3 py-1 text-xs">data-cursor="takeover"</span>
    </div>
  </div>

</div>

### Usage Examples

```html
<!-- Blend Dither Effect -->
<button data-cursor="blend">Hover for Blend Dither</button>

<!-- Takeover Effect -->
<div data-cursor="takeover" className="px-8 py-5 rounded-2xl border border-white/10">
  Hover me — Cursor will take my shape
</div>

<!-- Regular elements will show default dot -->
<a href="#">Normal Link</a>
```
