Runtime highlighting flashes. Build-time highlighting doesn't.

[rehype-pretty-code](https://github.com/atomiks/rehype-pretty-code) runs [shiki](https://github.com/shikijs/shiki) on the server. Editor-grade syntax, zero flash — and it'll highlight on the client too, when you need it to.

This post pushes every feature. Themes, line numbers, line highlighting, word highlighting, ANSI output, every meta string.
